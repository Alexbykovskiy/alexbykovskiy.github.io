▶ Torrent Player

Бесплатная браузерная версия для iPad и Safari

Поиск через сторонний TorAPI. Доступность не гарантирована.

В Safari доступны только WebRTC-пиры. Большинство обычных торрент-раздач не запустится без отдельного сервера.

Видео должно использовать кодек, который поддерживается Safari. Например, MP4 с H.264/AAC.

Это экспериментальный браузерный инструмент. Только для материалов, доступных для законного распространения. Браузерный WebTorrent не подключается к обычным TCP/UDP торрент-пирам.
